# Консольное приложение «Трекер прочитанных книг»

Назначение приложения
«Трекер прочитанных книг» — это консольный инструмент на Python, позволяющий вести учет прочитанной литературы, собирать статистику и анализировать свои читательские привычки. Все данные сохраняются локально в формате JSON.

Запустите главный скрипт через терминал или командную строку:
python main.py

=== Меню ===
1. Добавить книгу
2. Показать все книги
3. Показать среднюю оценку
4. Статистика по авторам
5. Удалить книгу
6. Выход
